# 🌸 Mental Journal

**Reflect, heal, and grow with a modern journaling experience.**

Mental Journal is a frontend web application designed to provide a simple and welcoming space for personal reflection and journaling. It features a clean interface with a pink-and-white color theme, intuitive navigation, and dedicated pages for exploring the application and accessing its dashboard.

## ✨ Features

- **Home Page:** A welcoming landing page with a prominent Mental Journal heading and a Get Started button.
- **Navigation Bar:** Easy navigation through Home, About, Login, and Dashboard.
- **About Page:** A dedicated page to introduce the application.
- **Login Page UI:** A frontend interface for the login experience.
- **Dashboard UI:** A dedicated dashboard page for the journaling experience.
- **Clean Design:** A minimal, modern interface with a soft pink-and-white theme.
- **Component-Based Structure:** Built with reusable React components.

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Language:** JavaScript (JSX)
- **Styling:** CSS
- **Development Tool:** Vite
- **Version Control:** Git and GitHub

## 📸 Application Preview

The home page features a large Mental Journal heading, a short introduction, and a Get Started button, alongside navigation links for Home, About, Login, and Dashboard.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js and npm installed
- Git installed

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the frontend directory:

   ```bash
   cd mental-journal/frontend
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal, usually `http://localhost:5173`.
